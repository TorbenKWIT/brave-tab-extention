# Brave new tab extention
use this extension if you want brave to open a specific web page when you create a new tab for example if your a self-hosting a search engine like searxng

# Install
clone the repo
Go to Brave settings under extensions
enable developer mode
click on load unpacked and select the folder where you cloned the repo
find the extension in the list and click details
click on Extension Options
enter URL that you want brave to go to when you open a new tab
